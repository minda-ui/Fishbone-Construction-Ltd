# Raw file index - FP 2401_131 Goathland Avenue

Every source document in this project folder, with the supplier and the document date.

The files arrived from Dext named only by their numeric Dext transaction id, which says
nothing about what they are. On 2026-09-05 each of the 99 files was opened and read, and
the supplier taken from the document itself. **The files were not renamed** - the Dext id is
the link back to Dext and to the Budget/Classifier notes written when the batch was
processed on 2026-08-25 - but they were moved into a folder per supplier, and this index
records what each one is.

Where the Date column says "not on the document" the file carries no readable date: those are
the Screwfix "Order History" screenshot PDFs, which have no text layer beyond the page title,
and a handful of till receipts whose date did not survive OCR. Those dates are recoverable
from the supplier account, not from the file.

> **The document files themselves are Drive-only.** `.gitignore` blocks `*.pdf`; the `.jpeg`
> scans are not mirrored either. This index is the only part of the folder that lives in git.

Construction Ltd on 31 October 2024, and several trade accounts were never updated. See

of Fishbone Drylining Ltd in this folder are this company's own purchases, not a related
